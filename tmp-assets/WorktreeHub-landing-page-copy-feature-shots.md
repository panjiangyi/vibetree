# WorktreeHub

把多分支开发，整理成一个真正可用的工作台

在一个本地 Web 应用里管理 Git worktree、打开真实终端、保留运行中的会话。少一点反复切分支，少一点窗口混乱，少一点上下文丢失。

## Hero

**为频繁并行开发的人设计的本地 Git worktree + Web Terminal 工作台。**

你不需要在多个目录、多个分支、多个终端窗口之间来回找上下文。WorktreeHub 把这些分散动作收拢成一个清楚的本地工作界面。

`立即开始`

`查看 GitHub`

## 核心卖点：setup 脚本，不再为每个新 worktree 重复做初始化

很多人愿意用 `git worktree`，但很快就会被一个现实问题拖慢：
**新 worktree 建好了，环境还没好。**

你还要重复做这些事：

- 安装依赖
- 跑项目初始化命令
- 启动 dev server
- 补齐每个仓库自己的本地准备动作

WorktreeHub 的思路不是只帮你“建一个分支目录”，而是继续往前走一步：
**把 setup 脚本作为项目级配置保存下来，让每次新建 worktree 都能更快进入可工作的状态。**

对于多仓库、多分支、频繁开新 worktree 的人，这个能力非常关键。它减少的不是一次命令输入，而是整套重复初始化流程。

![项目与 worktree 管理](./WorktreeHub-feature-project-sidebar.png)

## 功能 1：把项目和 worktree 放进一个清楚的侧边栏

每个项目下有哪些 worktree、当前在哪个分支、哪些工作区是 dirty、哪些分支已经 merged，一眼就能看清。你不用再靠文件夹命名或终端标题去猜当前上下文。

![项目与 worktree 管理](./WorktreeHub-feature-project-sidebar.png)

## 功能 2：常用动作放在最短路径上

添加项目、打开终端、刷新状态、重连会话，都在顶部操作区直接可达。它不是把 Git 命令藏起来，而是把高频操作压缩成更顺手的入口。

![顶部操作区](./WorktreeHub-feature-top-actions.png)

## 功能 3：一个 worktree，一个明确的终端会话

终端标签直接和 worktree 对应。你看到的不是一堆模糊的 shell 标签，而是具体到分支和上下文的工作单元，切换更直接，出错更少。

![终端标签与上下文](./WorktreeHub-feature-worktree-tabs.png)

## 功能 4：真实终端，不是假控制台

WorktreeHub 连接的是后端真实 shell，会话可以持续运行。你可以把它当成真正的开发终端来用，跑脚本、看输出、盯构建、守测试，而不是只看一块静态日志区域。

![实时终端面板](./WorktreeHub-feature-live-terminal.png)

## 功能 5：可以远程打开网页，继续写代码和盯任务

WorktreeHub 最实用的一点，是它把本地开发环境带进了网页。你不用守着那台机器的桌面窗口，只要能打开浏览器，就能重新进入对应 worktree 的终端上下文。

这带来几个非常直接的便利：

- 在另一台电脑上继续接着当前 worktree 工作
- 临时离开工位时，用手机查看构建、测试、脚本进度
- 浏览器刷新后仍能恢复终端会话，不用重新找现场
- 后端还活着时，浏览器断开不等于任务中断

它不是云 IDE 那种重平台路线，而是把你自己的本地开发机，变成一个更容易远程接入的工作台。

![远程打开网页继续工作](./WorktreeHub-feature-remote-web-coding.png)

## 功能 6：移动端不是“凑合能看”，而是专门能用

WorktreeHub 不只是允许你在手机上打开页面，而是真的把手机场景考虑进去了。顶部保留项目入口、终端入口、重连、设置和快捷操作按钮，适合你离开电脑时快速确认当前 worktree 和任务状态。

![移动端顶部操作](./WorktreeHub-feature-mobile-header.png)

## 功能 7：手机上也能直接查看终端输出

同一局域网下，用手机打开后可以直接看到当前终端内容。长时间构建、测试、脚本执行时，不必回到电脑前才能知道进度。页面针对手机宽度保留了清晰的终端视图，还配了方向键、Tab、Esc、Enter、Ctrl+C 这些快捷操作按钮，而不是简单把桌面内容缩小。

![移动端终端视图](./WorktreeHub-feature-mobile-terminal.png)

## 功能 8：为触屏补了终端快捷操作

把手机上的高频按键直接放到手边。方向键、`Tab`、`Esc`、`Enter` 和 `Ctrl+C` 都做成了快捷操作按钮，让你在手机上也能继续发命令、补输入、打断任务。

![移动端终端快捷键](./WorktreeHub-feature-mobile-controls.png)

## 为什么这比“多开几个终端窗口”更有效

- 每个 worktree 都是独立上下文，不再互相污染
- 页面刷新后，终端会话仍可恢复
- 浏览器断开后，后端任务还能继续运行
- 所有数据保存在本地，适合可信的个人开发环境
- setup 脚本让新 worktree 更快进入可工作状态
- 可以从浏览器远程重新进入你的本地开发上下文
- 同一局域网下可以从手机顺手查看状态
- 移动端保留了终端查看和基础交互能力
